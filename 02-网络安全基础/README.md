本周学习安全目标和威胁模型。

## 威胁模型

读一篇安全论文，先弄清以下问题：

| 问题 | 以本周选择的论文作答 |
| --- | --- |
| 要保护什么？ | 密钥、地址、用户行为，还是其他秘密？ |
| 攻击者在哪？ | 同进程、跨进程、跨虚拟机，还是远程网络？ |
| 能做什么？ | 运行代码、选择输入、重复查询、读取接口？ |
| 能观察什么？ | 时间、缓存、功耗、中断或其他信号？ |
| 需要哪些前提？ | 共享资源、特定硬件、权限或受害者行为？ |
| 破坏哪个目标？ | 机密性、完整性或可用性？ |

用第一周的 PLATYPUS 回答这些问题，思考：

1. 密钥窃取与隐蔽信道攻击是否实用？它们违反了 CIA 模型（机密性、完整性、可用性）中的哪些安全目标？

2. 特权攻击模型与非特权攻击模型有什么区别？

3. 哪些攻击案例（case study）被学术界广泛采用？
