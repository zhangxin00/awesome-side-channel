# 入组准备：看论文、做实验、写论文

[返回首页](../README.md) · [下一周](../01-如何阅读论文/README.md)

先学会三个常用工具：

| 工具 | 用途 | 练习 |
| --- | --- | --- |
| [Zotero](01-Zotero看论文.md) | 看论文、管理文献 | 导入论文，做批注，导出 BibTeX |
| [SSH 与北大 VPN](02-SSH与北大VPN.md) | 登录服务器做实验 | 登录、上传下载文件、恢复远程会话 |
| [LaTeX](03-LaTeX写论文.md) | 写论文 | 编译一页带参考文献的阅读笔记 |

三个练习可以用同一篇 [Spectre 论文](../01-如何阅读论文/2019-Spectre.pdf)，暂时读不懂的部分留到第一周。

访问 GitHub、论文网站遇到网络问题时，参照 [Clash：安装与简单使用](04-Clash网络代理.md)。订阅码请私聊张鑫老师获取。

Zotero 和 LaTeX 可以在个人电脑上练习。SSH 需要向管理员申请服务器账号，确认地址、端口和访问方式。北大 VPN 需要相应校园网账号，其他同学使用所在单位的网络入口。
