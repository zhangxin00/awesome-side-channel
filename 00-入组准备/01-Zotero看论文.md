# Zotero：看论文与管理文献

[返回入组准备](README.md) · [下一节：SSH 做实验](02-SSH与北大VPN.md)

Zotero 用来保存论文、做批注和管理参考文献。先用一篇论文走完流程。

## 1. 安装

从[官网](https://www.zotero.org/download/)安装桌面客户端和浏览器插件 Zotero Connector。保存论文前先启动客户端。

左侧是文献分类，中间是条目，右侧是标题、作者等信息。条目下可以放 PDF 和笔记。新建一个“侧信道入门”分类，把本教程的论文放进去；以后再按主题细分。

## 2. 导入论文

可以任选一种方式：

- 在论文详情页点击 Connector，保存条目和能获取的 PDF。
- 点击“通过标识符添加条目”，输入 DOI。
- 把本地 PDF 拖入 Zotero，尝试自动识别文献信息。

导入后检查标题、作者、年份、会议或期刊、DOI。识别有误就手动修改；缺少 PDF 时，从作者或会议网站下载，再拖到条目下面。具体操作见[添加条目指南](https://www.zotero.org/support/adding_items_to_zotero)。

本次使用 [Spectre](../01-如何阅读论文/2019-Spectre.pdf)。它有 2018 年预印本和 2019 年会议版，注意文件与引用信息对应。

## 3. 阅读与批注

双击 PDF 阅读，在关键段落旁写下自己的理解和疑问。读完后建一条笔记，简要回答：

- 论文想解决什么问题？
- 攻击者需要什么权限和条件？
- 方法是什么，实验说明了什么？
- 哪些地方还没读懂？

笔记格式自定。可以把批注加入笔记，点击后回到原文，操作见 [PDF 阅读器说明](https://www.zotero.org/support/pdf_reader)。分享批注时使用“导出 PDF”并包含批注，直接复制原附件可能不带批注。

## 4. 导出参考文献

右键论文条目，选择“导出条目”，格式选 **BibTeX**，保存为 `refs.bib`。

用文本编辑器打开它。`@inproceedings{...` 后面的名称是引用键，需要与 LaTeX 中的 `\cite{...}` 一致。Zotero 修改条目后，重新导出并替换项目里的 `.bib`。下一节会用它[编译阅读笔记](03-LaTeX写论文.md)。

## 5. 同步与备份

跨设备使用时，在设置中登录 Zotero 账户并开启同步。条目信息与 PDF 附件分别同步，能看到标题不一定表示附件已下载，详见[同步说明](https://www.zotero.org/support/sync)。

定期备份[数据目录](https://www.zotero.org/support/zotero_data)，复制前关闭 Zotero。不要把正在使用的数据库目录放进普通网盘同步文件夹。
