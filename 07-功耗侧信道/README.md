# 第七周：功耗侧信道

[返回首页](../README.md) · [上一周](../06-Cache侧信道/README.md) · [下一周](../08-Spectre及变体/README.md)

功耗侧信道利用计算过程中的功耗变化推断秘密。除了外接测量设备，也可以通过片上传感器、频率或执行时间观察功耗的影响。

## 本周论文

- [S&P'21] [PLATYPUS: Software-based Power Side-Channel Attacks on x86](2021-PLATYPUS.pdf)

- [CCS'22] [HammerScope: Observing DRAM Power Consumption Using Rowhammer](2022-HammerScope.pdf)

- [SEC'22] [Hertzbleed: Turning Power Side-Channel Attacks Into Remote Timing Attacks on x86](2022-Hertzbleed.pdf)

- [S&P'25] [Scheduled Disclosure: Turning Power Into Timing Without Frequency Scaling](2025-Scheduled-Disclosure.pdf)

## 本周任务

为上面的每篇论文写一段英文摘要，另找近 2 年的 3 篇功耗侧信道论文，按兴趣排序。摘要与文献清单随周五邮件发送，格式见[邮件示例](../01-如何阅读论文/Email格式.md)。

阅读本周原文，为每篇写出从功耗到观测量的路径，并记录所需接口、权限和平台条件。
