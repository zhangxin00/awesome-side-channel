# 第十一周：硬件安全与密码学

密码算法的数学安全性不等于实现的安全性。本周关注常数时间编程、编译优化与形式化验证。

## 本周论文

- [PLDI'23] [CryptOpt: Verified Compilation with Randomized Program Search for Cryptographic Primitives](2023-CryptOpt.pdf)

- [CCS'24] [Testing Side-Channel Security of Cryptographic Implementations against Future Microarchitectures](2024-Testing-Side-Channel-Security.pdf)

- [CCS'25] [Securing Cryptographic Software via Typed Assembly Language](2025-Securing-Cryptographic-Software.pdf)

- [ASPLOS'25] [Protecting cryptographic code against Spectre-RSB (and, in fact, all known Spectre variants)](2025-Protecting-Cryptographic-Code-Spectre-RSB.pdf)

## 本周任务

为上面的每篇论文写一段英文摘要，另找近 2 年的 3 篇硬件安全与密码学论文，按兴趣排序。摘要与文献清单随周五邮件发送，格式见[邮件示例](../01-如何阅读论文/Email格式.md)。

选择一个常数时间或形式化保证，写出其泄漏模型与硬件假设；检查论文是在优化性能、证明实现性质，还是扩展安全模型。
