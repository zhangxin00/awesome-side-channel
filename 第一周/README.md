# 如何阅读文章
首先，请了解本领域最好的会议（硬件安全最好的文章通常优先发表在会议上）和期刊 [defs.bib](./defs.bib)。通常不阅读除这些venue之外的文章，除非作者特别有名。

其次，请了解《计算机系统会议论文是如何评审的》和《对计算机体系结构研究的一点认识》，在本文件夹内可以找到。

在读文章时，需要重点关注Introduction和Method部分，Background和Evaluation仅作为补充材料阅读。在读完论文后，应在关闭论文后，凭印象重新为文章写一段摘要，不需要包含具体实验结果 (低年级同学可中文，高年级同学英文)。如果需汇报，还一份PPT，参考本文件夹内的参考.pptx 。
