# Awesome Side Channel：侧信道与硬件安全入门

本教程面向刚接触科研的本科生和低年级研究生。前 3 个月学习侧信道与微架构攻击的基础，后 3 个月结合兴趣复现实验、尝试研究问题。每周安排可按基础和设备条件调整，标注“选读”的章节按需学习。

## 怎么学

1. 入组前先熟悉 [Zotero、SSH 和 LaTeX](00-入组准备/README.md)，分别用于看论文、做实验、写论文。
2. 第一至三周补基础，第四周了解相关团队。从第五周起按主题阅读论文；先读懂一篇，再看其余工作。
3. 结合[实验代码](经典实验代码/README.md)动手复现。记录运行条件和结果，试着解释与论文不一致的地方。

第五至十二周，每篇指定论文写一段 100–150 词的英文摘要，不用大模型代写或润色。额外检索的论文按各周要求列出标题、作者和出处，按兴趣排序。“近两年”“近三年”均以学习时的日期为准。

| 阶段 | 主题 | 学习重点 |
| --- | --- | --- |
| 第 13–14 周 | FPGA、GPU 侧信道 | 平台特性与实验条件对照表 |

选题时想清楚：已有工作解决了什么，还剩什么问题，你准备怎样验证。
