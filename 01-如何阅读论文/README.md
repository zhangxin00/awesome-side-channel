# 第一周：如何阅读论文

[返回首页](../README.md) · [入组准备](../00-入组准备/README.md) · [下一周](../02-网络安全基础/README.md)

本周读 Spectre，练习找出论文的问题、方法和实验结论。

## 1. 认识论文来源

查看 [推荐会议与期刊.bib](推荐会议与期刊.bib) 中的会议缩写。安全方向常见 S&P、USENIX Security、CCS、NDSS；体系结构方向常见 ISCA、MICRO、HPCA、ASPLOS。论文很多，入门时主要关注这些会议、期刊，再按研究主题筛选。

## 2. 读两篇研究方法文章

阅读[《计算机系统会议论文是如何评审的》](计算机系统会议论文是如何评审的.pdf)和[《对计算机体系结构研究的一点认识》](对计算机体系结构研究的一点认识.pdf)。

## 3. 分三遍读论文

1. 第一遍看标题、摘要、引言和结论：明确问题、方法与观点，标记不认识的术语。
2. 第二遍看威胁模型、必要背景与方法：了解攻击成立的场景和原理。
3. 第三遍看评估与局限：挑一项核心结论，找到对应图表、基线与实验设置，检查论据是否充分。

第一遍不必弄懂所有细节。读不下去时，记下卡在哪里，再查背景资料。精读时要看实验是否支持作者的结论。

## 4. 本周论文与补充材料

阅读 **Spectre Attacks: Exploiting Speculative Execution（IEEE S&P 2019）**：[本地 PDF](2019-Spectre.pdf)。在 Zotero 中保存条目并核对版本。

观看视频 [An Introduction to Microarchitectural Attacks](https://www.youtube.com/watch?v=hgxPXGd_rR0)。

## 5. 本周任务

合上论文，用自己的话写一段摘要，随周五邮件发送。第一周可以用中文。需要做汇报时，可用 [PPT 模板](template.pptx)。
